# IO-Projekt-Repo

Plan i notatki do zadania projektowego „System obsługi i administracji sieci parków rozrywki”.

## Dokumentacja
- `docs/project_plan.md` — skrócony plan pracy w podejściu Scrum: Product Backlog, Sprint 1 Backlog, scenariusze wybranych przypadków użycia, słownik pojęć oraz zarys architektury i diagramów do przygotowania.

Repozytorium służy do gromadzenia artefaktów (diagramy UML, szkice raportu PDF, notatki) przygotowywanych zgodnie z wytycznymi kursu.

## Jak znaleźć i pobrać pliki (dla osób bez doświadczenia z programowaniem)
1. Wejdź na stronę GitHub z repozytorium (link widoczny u góry w przeglądarce na zrzucie ekranu). Jeśli linku nie masz, poproś o niego lub przekażę pełny URL.
2. Na stronie repozytorium kliknij zielony przycisk **Code** i wybierz **Download ZIP** – pobierzesz wszystkie pliki na dysk bez konieczności używania narzędzi programistycznych.
3. Rozpakuj archiwum ZIP na komputerze. Najważniejsze materiały znajdziesz w folderze `docs/` (zwłaszcza `docs/project_plan.md`).
4. Pliki w formacie Markdown (`.md`) możesz otworzyć w przeglądarce internetowej lub w darmowym edytorze tekstu (np. Visual Studio Code, Notepad++, a nawet zwykły Notatnik – choć VS Code zapewnia lepsze formatowanie).
5. Jeśli będziesz chciał wysłać dokumentację w PDF, otwórz `docs/project_plan.md` w VS Code i wybierz opcję „Drukuj do PDF” albo skopiuj treść do szablonu Word/Google Docs zgodnie z wymaganiami kursu.
